## 1. 計画への所見

計画は第1クールと同じ骨格（日常の場面 → 理論 → 同じ場面の見え方が変わる）を保ち、第13回と第24回を往復させ、第1クールとの重複回避を表で明示している。この骨格はそのまま採る。実装前に確認しておきたい点が7つある。

1. **出典は未取得である。** 計画に添えられた参照先（UCL Discovery、biolinguagem.com、arXiv、PubMed、OUP Academic、PNAS、College of Sciences、resalliance.org、PubsOnline、アメリカ経済協会、PMC）は、この環境ではまだ一つも取得・確認していない。第1クールと同じく `sources.json` の `checked` に「原文を読めた／書誌・抄録のみ／紹介ページのみ」を回ごとに記録する。特に biolinguagem.com（第14回）は二次資料の可能性が高く、原典（Bateson 1972 所収の "The Logical Categories of Learning and Communication"）を書誌に置く。
2. **第16回（因果創発）は条件を厳密に書く。** ホーエルらの有効情報は、離散状態のマルコフ系に最大エントロピーの介入分布を置いて定義される量で、粗視化の取り方に依存するという批判もある。計画のとおり一般法則として扱わず、本文で定義域を示し、批判の存在を脚注に記す。
3. **第18回（HOT）は「べき則の生成モデル」であることを外さない。** カールソンとドイルの枠組みは、設計された系が頻出の外乱へ資源を配分した結果として、稀な外乱に対する大規模な損失が生じる構造を示す。本文は "robust yet fragile" の対比に絞り、べき則の導出は脚注か省略にする。
4. **第19回は文献を二つに分ける。** ホリング1973年の定義（安定性とレジリエンス）と、1996年の工学的レジリエンスと生態学的レジリエンスの区別は別の文献である。どちらを主にするかを決める（推奨: 1973年を主、1996年を補助）。
5. **第21回（マーチ）の原モデルは組織コードと個人の相互学習のシミュレーションである。** 「探索と活用への資源配分」は概念整理の範囲で語り、数式を置くなら独自の説明用モデルと明記する。
6. **第23回（進化の大転換）の工学的応用は留保を厚くする。** 計画も同一視を避けると述べているが、第1クールの第5回より踏み込んだ類推（組織再編、Agentの増設）を扱うため、本文中の区別を第5回と同じ密度で入れる。
7. **第2クールにも `guides/STYLE.md` をそのまま適用する。** 命令形を使わない、各回の太字は1つ、結びは次回案内で終えない、次回案内は下部ナビゲーションへ、である。第24回は第12回と同じく強度「強」。

## 6. 執筆と検証の手順

### 6.1 順序

1. **構造変更だけを先に入れる。** §3 を実装し、既存12回のまま `validate.py`・テスト・ビルドが通ることを確認してコミットする（回帰の確認）。
2. **第13回をパイロットにする。** 出典の取得と `sources.json` 登録 → 構成メモ → 本文 → 図 → 検査 → レビュー。
3. **第Ⅰ部の残り（14〜16）、第Ⅱ部（17〜20）、第Ⅲ部（21〜23）を部ごとのバッチで進める。** 各バッチでレビューを受ける。
4. **第24回は最後に単独で書く。** 第13回の図と本文を再読してから書く。
5. 第2クールの表紙、README、CHANGELOG 2.0.0、Pages 再公開。

### 6.2 1回あたりの手順

1. 文献を取得し、`sources.json` に `author / year / title / url / note / checked` で登録する。原文を読めなかった場合は `checked` にそう書く。`bibliography.md` を同じコミットで更新する。
2. 構成メモ（場面、理論の要点、式の有無と種別、第1クールとの接続、結びの像、図の構図）を `claudedocs/season2/NN.md` に書く。
3. 本文を書く。`guides/STYLE.md` に従い、`rhythm_report.py --chapter NN` で計測する（新規本文なので前後比較はなく、§5 の規則への適合だけを見る）。
4. 図を `draw_figures.py` に追加し、生成して `svg_errors` を通す。
5. `validate.py` → unittest → `build.py` → `check_html.py`。ブラウザで図のラベルの重なりとモバイル幅を確認する。
6. `series.json` の `summary` と `sources` を本文と同じコミットで整合させる。

### 6.3 文体の数値目標（STYLE.md と同じ）

各節に15字以内の短文と60〜90字の長文を1つ以上、読点は40字以内で0〜1個、同じ文末3連続なし、「〜は」始まり4連続なし、問いは1回3つまで、留保の自己言及は1回3回まで、命令形なし。
