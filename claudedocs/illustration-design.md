- 図は「読者に描かせている段落」の直後、段落境界に置く。節をまたがない。

- `rhythm_report.py` は図とキャプションを本文から除外するので、文のリズムの計測値は変わらない。

## 2. スキーマと検査の変更

### 2.1 `series.json`

各回に `figures` 配列を追加する。`figure` は主図として残す。

```json
{
  "number": 3,
  "figure": "assets/illustrations/03-dissipative-structures.svg",
  "figures": [
    {"path": "assets/illustrations/03-2-pitchfork.svg", "label": "3-2", "section": "揺らぎが残る条件"}
  ]
}
```

`section` はその図を置く `###` 見出しの文字列で、検査と将来の配置確認に使う。追加図のない回は `"figures": []` とする。

### 2.2 `scripts/validate.py`

- SVG枚数の検査を「ちょうど13」から「`1 + 12 + Σ len(figures)` に等しい」へ変える（第1陣適用後は19）。
- 各回について、`figures[].path` のファイルが存在し、本文から参照され、参照箇所が `section` の見出し以降・次の見出し手前にあることを検査する。
- 既存の「`figure` が参照されている」検査はそのまま残す。

### 2.3 `tests/test_repository.py`

`svg_files` の期待値を 13 から 19 に変える。`figures` の `section` 検査について、正しい配置と誤った配置の両方の例を持つ小さな試験を1つ足す。

### 2.4 `scripts/draw_figures.py`

- `Figure.__init__` の `number` を `int | str` にし、ヘッダ表示を `f'{number:02d}' if isinstance(number,int) else number` にする。
- `main()` の `filenames` を `figure` と `figures[].path` の両方から組み立てる。
- 6点をそれぞれ関数 `figure_1_2(f)` … `figure_12_2(f)` に分け、`main()` から呼ぶ。既存13点の生成コードは変えない。

### 2.5 `scripts/manuscript_invariants.py`

図とキャプションは「変えてはいけない事実」として検査しているため、図を追加する改稿では `figures` と `captions` の差分が出る。`--allow-figures` オプションを足し、追加分だけを許容して、数式・数値・脚注の検査は維持する。

### 2.6 変更しないもの

`build.py`（`assets/` を丸ごと複製）、`check_html.py`（相対参照の存在を検査）、`browser_smoke.py`、`styles.css`。
