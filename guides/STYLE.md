# 文体とリズムの規則

[連載目次へ](../README.md)

本文の声を保ったまま、読みやすさと余韻を上げるための規則である。語彙、比喩、人称、口調は変えない。リズムのために事実を足したり、削って意味を変えたり、因果を付け加えたりしない。特定の作家に似せた語彙・比喩・口調を使わない。

## 変えないもの

- 事実、数式、数値例、固有名詞、脚注ID、図とキャプションの内容。
- [編集方針](EDITORIAL.md)の「明示した区別」。区別は残し、置き場所と言い方だけを変える。
- 常体。「私たち」の人称。仕事と具体物に根差した比喩。
- 各回の題名と副題。冒頭を具体的な場面から始める構成。
- 各回に太字の中心命題を1つ置く構成。

## 強度

| 範囲 | 強度 |
| --- | --- |
| 第1〜11回の本文 | 標準。連続する同形の文と読点の過多を直す |
| 各回の冒頭段落と最終段落 | 強。長短の配置、間、文末の変化を積極的に調整する |
| 第12回 | 強 |
| 数式ブロックの直前・直後の段落 | 最低限。事実の並びと読点だけを直す。文長の規則は免除 |

## 文

適用単位は節（`###`）とする。

- 各節に、15字以内の短文を1つ以上、60〜90字の長文を1つ以上入れる。25〜45字の文の連続は3文まで。
- 読点は、40字以内の文で0〜1個、長文でも2個まで。主語直後（「私たちは、」）と短い接続語直後（「しかし、」）の読点は外す。段落内で読点のない文が半数以上になることを目標とする。
- 同じ文末を3回続けない。「ではない」は1節に2回まで。体言止めは1段落に1回まで。
- 「〜は」で始まる文を4つ続けない。時、場所、対象、接続、条件、倒置から始める。
- 1文に入れる事実は1〜2点。並列の名詞は「と」「や」でつなぎ、読点で並べない。

## 段落と節

- 段落は3〜6文。1文段落は第1〜11回で各1つまで、第12回で3つまで。数式ブロックに接する段落は数えない。
- 段落末の文は次の段落へ渡す。結論で閉じる段落は節に1つまで。
- 太字は1回に1つ。節末の太字は通常文に戻す。
- 問いは1回に3つまで。そのうち1つは答えを本文で言い切らない。
- 転機（逆説、反転、「ところが」）は短文で刻む。理論の導入や経過は長文で流す。

## 留保と自己言及

- 「本連載の」「説明用」「〜の公式ではない」「〜を直接導く法則ではない」の類は、1回につき合計3回まで本文に残す。残りは図キャプション、脚注、文末の短い限定句（「〜の範囲で」「〜の模型として」）、節末の1文のいずれかへ移す。
- 移しても、編集方針の「明示した区別」が本文に1回は残ることを確認する。
- 「〜してはいけない」は使わない。「〜すると〜を失う」「〜は別に数える」のように、何が起きるかを叙述する。「べきである」は1回に1つまで。

## 冒頭と結末

- 冒頭の1文目は20字以内を目標にする。場面は変えない。
- 最終段落は「次回は〜」の案内文で終えない。問い、または像（具体物、未完の状態、動き続けている状態）で終える。最後の一文は短くする。
- 次回案内は `<!-- NAV:BOTTOM -->` ブロック内、区切り線の直後に斜体1行で置く。形式は `*次回　第N回「題名」。一文の問い。*` とする。

## 確認

```sh
python scripts/rhythm_report.py --chapter 03 --ref HEAD
python scripts/manuscript_invariants.py chapters/03-dissipative-structures.md --ref HEAD
```

`rhythm_report.py` は上の数値目標を測るだけで、合否は出さない。`manuscript_invariants.py` は数式・数値・脚注・図・キャプションが改稿前後で変わっていないことを検査し、変わっていれば終了コード1を返す。見出し・カタカナ語・太字の変化は参考として表示する。最後に全文を音読する気持ちで読み、つかえる箇所と同じ調子が続く箇所を直す。
